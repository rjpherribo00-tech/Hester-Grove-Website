## Publishing it for free with GitHub Pages

1. Go to https://github.com and create a **new repository** (e.g. `hester-grove-website`). Keep it public.
2. On the repo page, click **Add file → Upload files**, then drag in every file and folder from this project (keep the `assets` folder structure intact).
3. Commit the upload (the default commit message is fine).
4. Go to the repo's **Settings → Pages**.
5. Under "Build and deployment," set **Source** to "Deploy from a branch," pick the **main** branch and the **/ (root)** folder, then **Save**.
6. GitHub will give you a live URL like `https://yourusername.github.io/hester-grove-website/` within a minute or two.
7. To use your own domain instead: in that same Pages settings screen, enter your domain under "Custom domain," then add a CNAME record at your domain registrar pointing to `yourusername.github.io`. GitHub will show you the exact record to add.
